## 2. Deskripsi Proyek

Sistem Informasi Restoran Stateful merupakan aplikasi berbasis web yang digunakan untuk mengelola menu makanan, kategori menu, meja restoran, pemesanan pelanggan, pembayaran, dan laporan transaksi.

Aplikasi ini menerapkan pengelolaan keranjang pesanan per meja menggunakan Session di sisi server. Pesanan dapat ditambahkan beberapa kali sebelum transaksi diselesaikan melalui proses pembayaran dan disimpan ke dalam basis data.

## 4. Ruang Lingkup Fitur

- Master menu makanan dan minuman.
- Master kategori menu.
- Master meja restoran.
- Pemesanan menu berdasarkan meja.
- Pengelolaan keranjang pesanan menggunakan Session.
- Pembayaran dan penyimpanan transaksi ke SQL Server.
- Laporan menu terlaris dan omzet harian.
- Cetak struk pembayaran.
